# Ant Browser 1.9.5

本版本重点完善浏览器进程、网络和代理运行的故障证据采集。

### 稳定性与故障定位

- 调试端口断开时核对实际浏览器进程，不再仅凭端口消失误判浏览器已退出。
- 记录进程创建时间、退出码、工作集、私有内存、句柄数、关闭意图和启动器交接。
- 记录 CDP 连接阶段、页面/Worker 生命周期、网络错误码、请求阶段耗时、GPU 与子进程摘要。
- Windows 故障包关联 WER 事件和已有崩溃转储元数据；未取得的证据明确显示为未知，不推断为 OOM 或 GPU。
- Xray、sing-box、Mihomo 的预检和运行 stderr 独立轮换，代理退出与恢复证据关联到对应浏览器运行。

### 日志系统

- 关键 ERROR 和故障事件绕过普通异步队列，并支持持久化 Flush 屏障。
- 日志增加应用会话号、事件序号、操作关联、丢弃计数和写入健康状态。
- 每个环境运行保留有界时间线，故障自动生成脱敏 JSON 记录，支持重启后恢复和单次故障导出。
- 日志页支持按环境、运行和故障记录筛选，展开查看证据覆盖和未知原因。
- 日志不会保存 Cookie、Authorization、请求/响应体或完整敏感 URL；不会修改全局 Windows 转储策略。

### 验证说明

- 已通过 Go 后端全量测试、受影响代理与诊断测试、Go vet 和前端 TypeScript 检查。
- 已使用配置的 Chromium 151 内核验证 HTTP 失败、连接拒绝、日志采集和诊断事件链路。
- 本版本不更换用户配置的指纹浏览器内核；Chromium 151 临时 headless 伪装断言仍需按实际指纹配置单独验证。

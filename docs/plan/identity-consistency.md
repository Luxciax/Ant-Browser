基线：1.9.5 / c338386。仅本地开发，未授权推送发布。

## 范围

- 扩展下载版本按默认内核读取，空包/204 给出准确错误。
- macOS 内核导入对话框使用安全扩展名。
- 便携登录态检测平台和 App-Bound 支持范围，不绕过加密。
- 本地启动 API/CDP 校验 Host/Origin，保留原鉴权。
- 借鉴 #58：紧凑离线身份模板、结构化一致性校验、稳定种子、UA/内核版本协调、代理地理对齐、所有页面的 CDP 定位覆盖。

## 实现约束

现有 fingerprintArgs 是身份定义的持久化真源，结构化画像由其解析，不增加第二份可漂移配置或数据库迁移。旧环境不自动重采样；模板和修正需用户在编辑页主动应用并保存。不能由指纹池控制的屏幕、内存、GPU 字段不宣称生效。定位覆盖不授予网站位置权限。

## 验收

定向 Go 回归、前端类型检查、使用隔离临时用户目录的配置内核运行验证；不访问日常环境或浏览器凭据。正式打包留给后续 GitHub Actions。

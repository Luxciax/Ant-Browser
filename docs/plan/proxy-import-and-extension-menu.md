# 节点导入扩展与扩展菜单修复

范围：新增导入格式，修复扩展行三点菜单越界；不更换连接栈、浏览器内核或用户数据，不发布安装包。

## 交付

- “节点 / 订阅”入口可粘贴单条或多行节点、明文或 Base64 订阅、Clash YAML/JSON、单节点/节点数组、sing-box JSON outbounds。
- 分享链接：HTTP(S)、SOCKS5、VMess、VLESS、Trojan、SS、Hysteria/HY2、TUIC、AnyTLS；保留现有节点预览、分组、订阅绑定与刷新流程。
- URL 拉取、自动刷新、手动粘贴共用后端规范化。默认 8 MB 上限；保留原有远程 URL/DNS/重定向安全校验。
- 手动修改拉取内容解除订阅绑定，避免下一次刷新覆盖手动节点。解析/拉取期间锁定输入。
- 严格拒绝混合输入中的坏节点，不静默部分导入；错误不回显原始认证内容。
- sing-box 仅提取节点，不导入路由规则。跳过 direct/selector/urltest 等非节点出站；detour、多路复用、自定义拨号/TLS、不能保留的字段拒绝转换。SSR、XHTTP、SS 插件不新增协议实现。
- 保留原 UI 风格。扩展菜单逃离行容器裁切，右侧对齐避让、上下翻转、限高滚动，滚动/缩放重新定位；支持菜单键盘导航、Esc 恢复焦点、外部点击关闭和主题继承。
- 导入相关的 HTTPS 协议降级、IPv6 地址拼接与 TUIC 参数遗漏一并修正。TUIC heartbeat 在 sing-box 时长和 Clash 毫秒字段之间转换。

## 验证

- Go 表驱动测试：上述格式、Base64 变体/折行、中文及加号名称、DNS 保留、规范化幂等、混合错误不部分导入、字段/编码/端口错误、大小限制与错误脱敏。
- 相同测试内容经本地 HTTP 订阅服务及手动解析 API，节点数量一致。
- 分享 URI 转为规范节点后可被现有 Xray/sing-box 构建器及 Mihomo 映射器接收；验证 HTTPS、IPv6、Reality、TUIC 选项及心跳单位。不是远端真实节点连通性认证。
- TypeScript 类型检查。
- 隔离开发页：实际 FishExtensionsPage 使用合成扩展数据，菜单完整显示五项。边界夹具覆盖右下角、小高度滚动、缩放重新定位、深色主题、键盘首尾跳转、Esc 和外部点击。
- 实际导入 hook + 合成 Wails 接口验证：调用新解析接口、VLESS 预览、确认后追加保存、保留旧节点，以及编辑后解除 URL 绑定。不接触运行中 Ant Browser 或真实订阅。
- impeccable 定向检测无命中；按 React 清单检查新增菜单的副作用清理、事件监听、键盘操作及 loading 状态，不进行无关重构。

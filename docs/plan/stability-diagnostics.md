# 稳定性与诊断修复方案

基线：release/1.9.2 / 81c07ff。只修复影响连接、出口隔离、伪装验证和故障定位的问题。

## 行为与实现

1. 活动桥接由引用计数保护。测速不得因一次握手失败杀掉/换端口；退出恢复沿用同一端口，并保留实时引用计数。Mihomo 补齐同端口有限恢复及故障通知，不跨连接栈、不换出口。
2. 原代理绑定丢失时保留绑定并报错，禁止自动直连；过滤 no-proxy-server、proxy-bypass-list、auto-detect 等绕过绑定的参数。显式直连入口仍可用。
3. 复用现有日志写入器，默认结构化持久化，按大小/日期轮转、最多保留 5 个分片/7 天。旧默认配置升级一次，后续显式关闭仍被尊重。内存日志在文件异常时继续可读，队列与磁盘故障可见。
4. 每个运行环境建立可取消 CDP 观察会话：浏览器级 Target 崩溃/销毁、页面 Network.loadingFailed、HTTP 错误及耗时统计、Inspector 崩溃。不采集 Cookie/请求头/响应体/聊天内容，不主动向网站发健康探针；只保存域名和分类。断开有限重连，环境退出/应用关闭取消。故障更新 RuntimeWarning，恢复日志保留前后时间线。
5. 启动记录 run_id、实际内核版本/路径、内存配额和配置；运行退出保留 stderr 尾部。指纹实测明确“通过/不匹配/未验证”，核对关键显式参数，并读取 Worker 一致性；不把版本号或参数下发当作完整认证。
6. 两套日志页显示真实读取失败，保留上一份日志；支持导出本地 JSON 诊断包（版本、运行状态、脱敏配置摘要、近期持久化日志、相关事件）。不上传。

## 验收和停止条件

- 回归：活动 Xray/sing-box/Mihomo 握手失败不会杀旧进程或丢引用；缺失绑定不变直连；绕过参数被拒绝。
- 恢复：代理意外退出保持原端口/出口，停止时不复活；恢复失败有明确环境关联和日志。
- 诊断：合成 CDP 事件可记录网络失败/渲染崩溃，URL 查询与凭据不进入记录；取消观察会话不泄漏 goroutine。
- 日志：轮转真实生效、异步错误可见、重启可读历史、导出可解析且脱敏；读取失败不显示“暂无日志”。
- 指纹：基础显式期望/Worker 差异正确判定，无法验证项明确显示未验证。
- Go 受影响包测试、前端类型检查和有限浏览器验收。若环境阻塞，先定位再替代，不扩大超时重复。
- 达到上述条件结束。源码本地提交；push/CI 发布/安装替换仍按外部写入与发布预览确认。

## 使用与边界

- 日志页可直接查看事件和导出本地 JSON，导出不上传；清空只清内存列表，不删除磁盘历史。默认日志目标为 `data/logs/app.log`（仍按应用状态根目录解析），20MB/日期轮转，最多 5 个分片、最长 7 天；导出读取当前文件及最多 2 个近期分片，最多 2000 条，并合并未落盘的内存日志。
- 旧默认配置只迁移一次到版本 3；版本 3 后明确关闭文件日志保持关闭。旧版本的“默认关闭”和“手动关闭”无法完全区分，此次仅匹配原默认路径、text 格式和未启用轮转的组合；自定义路径保持原设置。
- 指纹自测结论是 `passed_basic / mismatch / unverified`。基础通过不等于 Canvas/Audio/WebRTC/字体/跨平台伪装认证；本轮不新增或重编译 Chromium 指纹补丁。
- 没有足够历史现场证据证明主人此前那次断网的唯一根因；本轮修复已确认的高影响风险并补齐之后可用的现场证据，不宣称历史事故已复现修复。
- 当前仅本地源码交付；未 push、未发布、未生成正式安装包、未替换安装版或修改用户环境数据。发布/安装和真实代理长时间稳定性仍待独立验收。
